# Rosendin Analytics (prototype)

A back-office analytics page for the BuilderFAX Rosendin pilot. It covers what workers add to their own
profiles - personal credentials, work experience and work samples - separate from the existing
assigned-credential analytics in the workbench.

Tabs: Overview, Personal credentials, Work experience, Work samples, Workers (drill-down table).

All workers and numbers are fictional demo data for prototype review. Nothing is sent or saved.
