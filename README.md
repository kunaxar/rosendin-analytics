# Rosendin Analytics (prototype)

A back-office analytics page concept for BuilderFAX employer accounts. It covers what workers add to their own
profiles - personal credentials, work experience and work samples - separate from existing
assigned-credential analytics.

Tabs: Overview (insights across all areas, with on-demand actions: credential table + detail drawer, issuer list, Excel report download, expiry nudges) and Workers (drill-down table with full worker profiles; verification can be requested on a specific experience record or work sample there).

All workers and numbers are fictional demo data for prototype review. Credential and trade names are
illustrative only, not real requirement data. Nudges and verification requests are simulated; nothing is sent.
